# Независимая проверка MeetFlow

Этап 5 плана сведения. Ветка meeting-registry проверяет MeetFlow, не правя его. Каждый пункт писем 01 и 02
— тест на исправленное поведение. Падает — дефект на месте, проходит — исправлен. Тесты, которые проходят
и до правки (отрицание снятия, тёзки, которые обе говорили), — стражи: они не должны сломаться при правке.

Запуск из этой папки:

```bash
python -m pytest -q -p no:cacheprovider -rA
```

Стражи из набора самой ветки MeetFlow — прогонять вместе с нашим набором (кнопка «Подтвердить» реально
выполняет действие):

```bash
cd "<папка meetflow-framework>" && python -m pytest -q -p no:cacheprovider "tests/test_letter02_stage2.py::test_held_task_accept_creates_task" "tests/test_letter02_stage2.py::test_closing_card_accept_closes_task" "tests/test_letter02_stage2.py::test_mass_card_accept_applies_all" "tests/test_letter02_stage2.py::test_disputed_name_choice_creates_task_without_rule" "tests/test_package01.py::test_cancellation_is_not_done"
```

Код MeetFlow только импортируется. База в памяти, кеш Python не пишется, в папку MeetFlow ничего не
попадает.
