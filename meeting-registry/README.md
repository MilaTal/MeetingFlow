## Состав папки

«PROJECT_REPORT.md» — итог, результаты тестов, уроки, вопросы и заглушки. «GLOBAL_SESSION_SUMMARY.md» —
журнал сессии. «01_Этап 0 — сканирование проекта.md» — что просмотрено и что найдено. «02_Профиль проекта.md» —
бизнес-контекст, данные, инфраструктура, критерии успеха. «03_Паспорт агента — meeting-registry (Р0–Р8).md» —
десять шагов курса. «05_Знания скилла» — паттерны, анти-паттерны, шаблоны, журнал моделей. «06_Журнал
улучшений.md» — что думали, что намерили, что сделали. «07_демо» — прогон без человека: папка-приёмник,
реестр, журнал прогонов, протоколы. «08_Deck — meeting-registry.md» — шесть слайдов и сценарий скринкаста.

«skill/meeting-registry» — скилл: SKILL.md, СЛУЧАИ.md, references/контракты.md и engine — движок с
тестами, наборами eval и скриптами атак. «00_промежуточные» — выжимки курса и сессий, отчёты
читающих агентов и ревьюера, скрипты этапа 0.

## Как проверить за две минуты

```bash
cd "skill/meeting-registry/engine"
python -m pytest tests -q
python eval/run_eval.py --label проверка --set cases_blind
python eval/cost_attack.py
```

Нужен Python 3.11 или новее. pymorphy3 и python-docx необязательны, без них работает мягкая деградация.
Модель для проверки не нужна — движок идёт на правилах. С моделью добавляется `--client ollama --model <имя>`.
