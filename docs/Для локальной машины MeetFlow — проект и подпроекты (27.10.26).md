## Что проверить на экране

Для каждого пункта ответ — «так» или «не так: что». Отличия, записанные в отчёте, не присылать.

**Суперадминистратор.**
- «Параметры системы» → «Проекты»:
  - завести подпроект у рабочего проекта через поле «Надпроект»;
  - переименовать его, задать варианты написания;
  - убрать в архив и вернуть;
  - сделать проект подпроектом собственного подпроекта — должен прийти отказ.
- Внизу левой панели: «Все проекты», проект, под ним подпроект с отступом. Выбрать подпроект — шапка «Проект — Проект – Подпроект».
- «Мониторинг RealTime» при выбранном подпроекте: своя папка-приёмник, отдельная от папки проекта.
- «Настройки» → «Подпроекты проекта»: тот же список, что на «Проектах». Убрать строку — подпроект уходит в архив.

**Администратор проекта.**
- Реестр при выбранном проекте:
  - видны задачи проекта и его подпроектов;
  - у задачи подпроекта перед формулировкой «Проект – Подпроект:»;
  - рядом с видами выбор «Весь проект … / подпроект / без подпроекта», он сужает список.
- Подпроект задачи: ✎ «Изменить задачу» → поле «Проект и подпроект» (пункты «Проект – Подпроект») переносит задачу, в истории строка «проект: Проект – Подпроект».
- Страница встречи → «Ещё» → «Подпроект встречи». Встреча переходит, в «Встречах по проекту» у неё подпись подпроекта.
- Договорённости: фильтр проекта с подпроектами. При «Все проекты» — пункты «Проект» и «Проект – Подпроект».
- «Статус проекта» → «Сводка» по проекту считает задачи подпроектов.

**Участник.**
- Видит проект с подпроектами внизу панели, приставку и фильтр в реестре.
- Подпроект задачи и встречи поменять не может: правок нет, сервер отвечает 403.

## Чего не делать

Не править `meetflow/meetflow/web/`: экраны держит машина разработчика. Перенос встречи в другой проект и проект записи из общей папки делает агент протокола.
