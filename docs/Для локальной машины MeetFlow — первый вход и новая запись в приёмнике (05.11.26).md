## 2. Кнопка и приёмник: два разных пути

В записке `904ef48` это уже сказано, теперь главное требование:
- кнопка «Пересобрать протокол»: только администратор и суперадминистратор, сервер отказывает остальным;
- новая запись в папке-приёмнике: система сама забирает файл сразу и сразу пересобирает протокол той же встречи с учётом этой записи. Роль здесь не проверяется, ничего нажимать не надо.

Проверь по факту и напиши числами: запись к встрече с готовым протоколом в приёмнике; файл забран; распознан; протокол пересобран и содержит новую запись; номера задач сохранены; после обрыва по пределу задачи не сняты. Сейчас в коде автосборку ставит только расшифровка (`intake.py:270`, `автозапуск_включён`). Если настоящая звукозапись идёт другим путём или ждёт чего-то, это расхождение: скажи и почини. На тестовой короткой записи с вымышленными данными и заглушкой модели, без денег. Тест на оба пути, что отказ кнопки не задевает приёмник.
