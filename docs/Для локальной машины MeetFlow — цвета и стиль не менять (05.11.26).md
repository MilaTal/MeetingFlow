# Для локальной машины MeetFlow — цвета и стиль не менять (05.11.26)

Слово владелицы от 05.11.2026: цветовые решения и стиль дизайна MeetFlow и других систем не меняются, всё сохраняется. Это условие для всех пакетов упрощения фронта (А, Б, В, Г) и для следующих записок по фронту.

Меняются только расположение, состав и подписи. Палитры, темы, токены цветов, шрифты, размеры, отступы компонентов, вид кнопок, вкладок и панелей не трогать. Новые элементы собирать из готовых классов. Если шаг нельзя сделать без новой стилевой правки по цвету или виду — не делай его, строка в журнал и отчёт. В отчёте дай `git diff --stat` по файлам `.css`: правки там только для раскладки, каждая с причиной.
