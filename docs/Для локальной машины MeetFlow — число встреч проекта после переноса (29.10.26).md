# Для локальной машины MeetFlow — число встреч проекта после переноса (29.10.26)

По отчёту `83714c5`, шаг 4. Сразу после «Переместить в проект…» окно удаления проекта писало «Встреч в нём нет», и верное число появлялось только после Ctrl+F5. Причина в том, что блок «Проекты» запоминал число встреч при загрузке страницы и после переноса его не перечитывал. Теперь список проектов перечитывается после переноса, удаления встречи и отмены удаления, а окно удаления проекта берёт число встреч с сервера. Статика — `20261029mf18`.

## Развернуть

1. `git pull --no-rebase origin dogonyaem-planerku`, перезапустить MeetFlow, Ctrl+F5. В коде страницы должна стоять версия `20261029mf18`.

## Проверить кликами, без перезагрузки страницы между шагами

1. «+ Новый проект» → «Проба счётчика».
2. Любую встречу из «Общих встреч» перенести в «Проба счётчика» через «…» → «Переместить в проект…».
3. У «Проба счётчика» «…» → «Удалить». Окно должно назвать «Встреч в нём: 1». Подтвердить, встреча вернётся в «Общие встречи». Если встреча была из рабочего проекта, вернуть её туда тем же «Переместить в проект…».

Скриншот окна шага 3 положить в Tests. Ответ — «так» или «отличается: что».
