# Для локальной машины MeetFlow — Д7 заменён: проект в форме, без лишних уведомлений (06.11.26)

Решение владелицы 06.11.2026 по макетам: вариант 2. Раздел Д7 записки `07b1234` отменяется и заменяется этим. Вопросов ей не задавай, денег не нужно. Порядок: после Д1, Д2 и строки над экраном (Д4).

## Что сделать

1. **Кнопки короткие, без проекта и даты:** «Создать встречу», «Перенести», «Удалить». Длинных подписей вида «Создать встречу 12.11.2026: Внедрение CRM» нет.
2. **Проект назван один раз в самой форме создания:** первой строкой формы «Подготовка встречи» текстом «Проект: Внедрение CRM», не поле ввода. Сменить проект — в строке над экраном.
3. **После создания уведомления нет:** человек сразу попадает на страницу новой встречи, а её строка называет проект.
4. **Короткое уведомление только там, где экран не меняется** и проект может быть не тот, что на экране: отметка «сделано» при «Все проекты» — «№ 101 отмечена в проекте «Переезд ЦОД»»; перенос встречи — «Встреча перенесена в «Переезд ЦОД»». Без ссылок, исчезает само.
5. **Окна, которые уже есть** (сборка, удаление, перенос), называют проект одной строкой текста, если его нет на экране за окном. Новых окон не добавлять.
6. **Остаётся как есть:** при «Все проекты» создание без явного выбора проекта невозможно; после переноса выбор уходит за встречей (А2-П23); в строке «Ближайшая встреча» при «Все проекты» назван проект (А3-13, А1-16).

## Как проверить

1. Подпись каждой кнопки действия — не больше трёх слов, проекта и даты в ней нет.
2. В форме создания проект назван 1 раз; после создания уведомлений 0, открыта страница встречи.
3. Отметка «сделано» при «Все проекты» и перенос встречи дают по одному уведомлению с названием проекта; при выбранном проекте отметка уведомления не даёт.
4. Весь набор тестов; тест, закреплявший прежнее, переворачивай.
