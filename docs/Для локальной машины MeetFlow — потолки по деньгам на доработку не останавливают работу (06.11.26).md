# Для локальной машины MeetFlow — потолки по деньгам на доработку больше не останавливают работу (06.11.26)

Слово владелицы 06.11.2026: «потолок по деньгам можно поднять сейчас для доработки… не останавливаемся из-за этого».

**Что меняется.** Потолки в записках на доработку больше не точки остановки. Это касается потолков замеров А, Б, В и тени варианта C, пересборок на копии и проверок. Дошёл до потолка — работа идёт дальше, в журнал пишется строка «потолок N $ пройден, продолжаю», в отчёте фактический расход. Если записка требует потолок обойти, решение не нужно: решение уже есть.

**Что остаётся.**
- Расход после каждого прогона — в отчёт: вызовы, $, PID, модель.
- Остановка, если зацикливание: те же вызовы повторяются, ошибки подряд, расход растёт без новых результатов. Это сбой, а не потолок. Остановить, разобрать, написать.
- Баланс ключа DeepSeek общий с другим проектом. Если до нуля осталось меньше 3 $, сразу строка владелице в отчёт: баланс и примерный расход на остаток работы. Работу не останавливать, пока баланс не исчерпан.
- Предел на один прогон в боевых системах (`LLM_MAX_COST_PER_RUN_USD`, «Модели») для живых встреч не менять. Если в него упирается прогон доработки на копии, поднять предел только для этого прогона и записать в журнал.

Остальное по прежним запискам: вариант C и таймаут распознавания (`85642d3`), остаток Д2, перенос 13 правок (`fc6bb33`).
