**Правило.** Файл `.ps1`, в котором есть байты ≥ 0x80 (кириллица), обязан начинаться с `EF BB BF`. Файл только из ASCII может быть без BOM. Сейчас под правило попадают:

| Файл | BOM | не-ASCII | Разбор сейчас |
|---|---|---|---|
| `meetflow/scripts/run_dev.ps1` | есть | есть | 0 ошибок |
| `meetflow/public/scripts/run_dev.ps1` | есть | есть | 0 ошибок |
| `meetflow/scripts/run_tests.ps1` | **нет** | есть | 0 ошибок (пока: «ё» и smart-quote байтов нет) |

`run_tests.ps1` — тот же риск: любая правка с «ё» или «—» в комментарии уронит разбор.
