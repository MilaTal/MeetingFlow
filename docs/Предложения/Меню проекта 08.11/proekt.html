Проект → его меню · 08.11
А · Проект раскрывается — ровно ваша стрелка (рекомендую). Список «Встречи по проектам» остаётся, как сейчас. Выбранный проект раскрывается на месте: его меню стоит прямо под ним, с отступом и линией слева, остальные проекты свёрнуты ниже. Нажмите другой проект — меню переедет к нему. Служебное (Команда, Разбор, Параметры) — ниже черты, оно не про проект.
  • Плюс: связь «проект → его меню» видна сразу; список проектов всегда под рукой; ваши правки 08.11 («Показать ещё» после четырёх, подпись блока) сохраняются.
  • Минус: при выбранном проекте внизу списка меню сдвигает остальные проекты; при 10+ проектах список нужно сворачивать (уже есть «Показать ещё»).
Б · Две колонки. Слева узкая полоса значков проектов (две буквы, как в мессенджерах), рядом — меню выбранного проекта с его названием сверху. Это и есть «меню второго плана» в чистом виде.
  • Плюс: уровни разделены жёстко: полоса — какой проект, колонка — что в нём.
  • Минус: по двум буквам проект не узнать, нужна подсказка при наведении; ещё 64 px ширины.
В · Шаг внутрь проекта. Сначала в панели только список проектов. Выбрали проект — панель целиком показывает его меню, сверху «← Встречи по проектам» и название проекта. Чтобы сменить проект, шаг назад.
  • Плюс: в каждый момент один уровень, ничего лишнего.
  • Минус: сменить проект — на одно нажатие дольше; список проектов не виден, пока работаешь внутри.
Г · Переключатель вверху — как решили 06.11 (пакет Д3), но не сделано. Вверху блок проекта с уголком, по нажатию — список поверх страницы с поиском; под блоком всегда меню выбранного проекта.
  • Плюс: компактно, меню не прыгает, подходит для многих проектов.
  • Минус: проекты спрятаны в список, связь «выбрал → меню» читается хуже, чем в А.
