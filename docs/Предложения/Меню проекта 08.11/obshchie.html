Меню общих встреч · 08.11
1 · Ваш вариант (рекомендую). Меню зависит от того, что выбрано. У проекта — полное меню, как сейчас. У «Общих встреч» проекта нет, поэтому группы «Инфо по проекту» и пункта «Статус проекта» нет вовсе; остаются «Реестр встреч», «Подготовка встречи», «Актуализировать задачи из реестра». Договорённости — только внутри выбранной встречи: откройте встречу в реестре, там вкладка «Договорённости встречи». Переключайте «Общие встречи» и проект слева.
  • Плюс: в меню нет пунктов, которые здесь ничего не покажут; договорённость видна там, где она родилась — во встрече.
  • Минус: общего списка договорённостей по всем общим встречам нет — только по одной встрече.
2 · Договорённости списком (запасной). Как 1, но у «Общих встреч» остаётся один пункт «Договорённости по встречам» — все договорённости общих встреч одним списком, у каждой дата встречи и переход в неё.
  • Плюс: всё сразу, без захода в каждую встречу.
  • Минус: расходится с вашим п. 3 — договорённости показываются вне конкретной встречи.
3 · Пункты серыми (не рекомендую). Пункты проекта видны и у «Общих встреч», но неактивны, с подсказкой «Только для проектов».
  • Плюс: меню у всех групп одной формы.
  • Минус: практика — неактивным оставляют только то, что станет доступно позже; пункт, который здесь не заработает никогда, только отвлекает.
