# Сборка по обеим расшифровкам (24.10.2026, уточнение 25.10.2026)

**Пакет:** Планёрка и ERP, записки «сборка по обеим расшифровкам» и «откуда цитаты при двух расшифровках»,
DECISIONS 24.10.2026. Когда у встречи есть загруженная и своя локальная расшифровка, сборка идёт по обеим: каждый
источник своим блоком, загруженная первой, строки сквозные; деление на темы внутри блока; дубли сводятся кодом по
формулировке, исполнителю и сроку; потолок вызовов — по сумме текстов; одна расшифровка — как раньше.

**Применимо: да, приоритет 3 (после группы 1).** В MeetFlow сейчас в сборку идёт один источник (`safe_source`),
вторая расшифровка теряется. Это прямая потеря поручений — у 16.10 и 21.10 в Планёрке текст был 20–28 тыс. знаков
против более длинного загруженного.

Что перенести:
1. Все действующие расшифровки встречи — блоками с подписью «загруженная» / «локальная, с голосами», сквозная
   нумерация строк.
2. Подсказку двух расшифровок: одна дополняет другую, имена из локальной, факта из одной достаточно, не дублировать.
3. Сведение дублей кодом (формулировка + исполнитель + срок), счётчик сведённых в итоге сборки.
4. Потолок вызовов по сумме знаков (8, выше 72 тыс. — до 12).

Что не переносить: замер происхождения цитат (25.10.2026) — это измерение для решения владелицы о выгрузке ВКС, не
функция продукта. В MeetFlow он пригодится только как метрика набора (строка 8), отдельно.

**Объём:** 6 ч. **Статус:** в таблице отставания новой строкой, очередь — после группы 1, перед узким порогом.
