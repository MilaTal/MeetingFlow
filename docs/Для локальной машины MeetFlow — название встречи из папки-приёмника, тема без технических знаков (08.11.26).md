# Для локальной машины MeetFlow — название встречи из папки-приёмника: без «из папки-приёмника:» и технических знаков, тема по содержанию + дата (слово владелицы 08.11.26)

Владелица 08.11.2026: сейчас встреча из папки-приёмника называется «из папки-приёмника: <имя файла>». Технический комментарий убрать, оставить только тему. Технические знаки из имени файла (расширение, подчёркивания, время, номера записи и т. п.) в систему не переносить. Название встречи создаётся автоматически: тема по содержанию + дата.

## Где сейчас

- `core/intake.py:234` — `метка = f"из папки-приёмника: {item.path.name}"` (проект не узнан, «Общие встречи»).
- `core/intake.py:326` — `label="из папки-приёмника"` (проект узнан, `_meeting_for`).
- `intake.py:235` ищет уже заведённую встречу **по этой метке** (повторный проход, пока запись распознаётся). Поэтому метку нельзя просто убрать: имя файла переезжает в отдельное поле.
- Показ: `app.js:4374` и `4037` — «Встреча дд.мм.гггг — <label>» (`cleanLabel`). Дата уже в названии, её в `label` не добавлять.

## Что сделать

1. **Одна функция** `тема_из_имени_файла(имя) -> str` (например, в `core/proekt_zapisi.py` рядом с `_тема_знак` — там уже есть часть правил). Убрать:
   - расширение (`.m4a`, `.mp3`, `.wav`, `.mp4`, `.ogg`, `.txt`, `.docx` и любое другое);
   - даты и время в любом виде (`2026-11-05`, `05.11.2026`, `20261105`, `10-30`, `10_30_15`, `10.30`, `GMT+3`);
   - технические слова записи: `rec`, `record`, `recording`, `audio`, `video`, `zoom`, `meet`, `telemost`, `запись`, `копия`, `copy`, `(1)`, `final`, номера вида `0012` или `#12`, GUID и длинные последовательности цифр и латиницы без смысла;
   - знаки `_ . - + = # @ [ ] { } ( ) ~ ^ ; ,` заменить пробелом; повторные пробелы свести; знаки по краям обрезать; первая буква прописная.
   - Осталось меньше трёх букв подряд — темы нет, вернуть пустую строку.
2. **Метка встречи при приёме** = эта тема, без «из папки-приёмника». Темы нет — `label` пустой, на экране «Встреча дд.мм.гггг».
3. **Тема по содержанию.** Если по имени файла темы нет, после сборки протокола взять её из содержания: строка «Предмет» протокола (`korotkiy_protokol`, как она уже читается) или действующая тема встречи (`topics.тема_встречи`) — что есть. Ставить, только если `label` пустой и встреча заведена автоматически. Метку, которую задал человек («Переименовать»), не трогать никогда.
4. **Имя файла — в отдельное поле**, например `meetings.source_name` (миграция) или поиск по таблице источников встречи. Повторный проход ищет встречу по дате и этому полю, а не по `label`. Тест: повторный проход того же файла не заводит вторую встречу.
5. **Откуда тема** — для истории и «Разбора»: `label_source` = «имя файла» / «протокол» / «тема встречи» / «вручную». На экране не показывать (правило «документы и экраны без технических меток»).
6. **Уже заведённые встречи.** Метки, начинающиеся с «из папки-приёмника», привести к новому виду той же функцией: сначала сухой ход числом (сколько, сколько стали пустыми), потом применить на копии базы, потом на рабочей. Строка в журнал с числами. Метки, заданные вручную, не трогать. Протоколы не пересобирать: меняется только название встречи.
