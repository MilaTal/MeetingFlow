# Для локальной машины MeetFlow — срочно: поиск места цитаты, раньше платного замера (05.11.26)

Машина ERP и Планёрки на 7 задачах с цитатой получила 0 совпадений места. Я воспроизвёл причину на вымышленной записи. Файл `core/ispolnitel_strazh.py` у тебя той же редакции (`def _место`, строка 289), `core/obedinenie.py` `окно`. Решения приняты разработчиком по поручению владелицы, вопросов ей не задавай.

`_место` считает долю основ по 5 букв и берёт первую лучшую строку. Реплика среди похожих возвращает первую строку, длинная строка раньше по записи забирает цитату, а `окно` считает индекс по всем строкам, а `_место` по непустым. Из-за этого: окно уточнения в `obedinenie` чужое, и по нему модель отвечает «не понять»; окно исполнителя и отказы сторожа могут ошибаться; короткая цитата строится отдельно и этого не лечит, но её сравнение может.

2. Не жди правку близнеца из `main`, сделай у себя тем же способом: сначала дословный поиск цитаты или куска от 8 слов подряд; если нет, доля основ с плотностью, при равенстве не первая строка; ниже порога `None`; окно по тому же списку строк. Тесты, падающие до правки: реплика среди похожих, длинная раньше, пустые строки, две строки, ничего не подошло. После замера верни `1`.
