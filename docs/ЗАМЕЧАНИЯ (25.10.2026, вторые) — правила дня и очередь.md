## 2. Защита от сбоя сборки

Сборка протокола никогда не остаётся «не удалась» молча. Причины делятся на два рода. **Проходит сама** (модель недоступна, сеть, таймаут, перезапуск службы, очередь): автоматический повтор с паузой — через 10 минут, затем через час, не больше двух; переключение на запасную модель — только при недоступности; каждый повтор — строкой журнала с `run_id`. **Сама не пройдёт** (вход больше предела, ответ не в формате после переспросов, обрыв по потолку длины): повтора вслепую нет, одна карточка в «Разборе» с причиной и действием «Пересобрать». На экране встречи — короткая понятная причина и следующий шаг, не «смотрите технические сообщения». Сборка, прерванная перезапуском, продолжается с сохранённых шагов.

## 3. Имя говорящего

1. Голос опознан по отпечатку (близость ≥ 0,65, отрыв ≥ 0,10) — имя по голосу. Всегда, что бы ни было в выгрузке ВКС.
2. Голоса нет, есть имя аккаунта ВКС — в тексте подсказка с пометкой «Фамилия И. (аккаунт ВКС)»: модель её видит, но исполнителя по «я сделаю» она не даёт — для этого нужна подпись голосом. Аккаунт — не говорящий: с чужого аккаунта может говорить коллега.
3. Ни голоса, ни аккаунта — «Говорящий N».
4. С одного аккаунта два голоса и больше — подсказка аккаунта не ставится никому.
5. В «Разборе голосов» у неопознанного голоса — предложение «аккаунт ВКС: …?» одним действием.

## 4. Одна расшифровка

Текст сборки — из своей (локальной) расшифровки; выгрузка ВКС — только источник подсказок имён. Страховка: своя явно неполная (знаков меньше 0,5 от выгрузки, или по времени покрывает меньше 70 %, или пустая) — текстом идёт выгрузка. Выбор и причина — в итоге сборки. Блоки «Расшифровка 1/2», правило «одна дополняет другую» и сведение дублей двух расшифровок — не переносить (отменено).
