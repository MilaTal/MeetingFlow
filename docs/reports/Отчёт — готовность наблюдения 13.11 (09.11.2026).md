# Готовность наблюдения 13.11: «строк нет» теперь отличается от «журнала нет» (09.11.2026)

План, пункт 7, шаг 2. Инструмент итоговой таблицы умел отличать пустой журнал (код 1) и нарушение условия варианта C
(код 2), но **молча** печатал пустую таблицу, если за окно были только демонстрационные сборки. На 13.11 это самый
вероятный случай: рабочая база с 08.11 не пересобиралась, в журнале одна демонстрационная строка.

## Что добавлено

- **Раздел «Готовность наблюдения»** в таблице: рабочих сборок в окне, встреч, строк с базовой линией; при нуле — прямая
  фраза «Недельного наблюдения нет… решение принимается по срезу».
- **Код возврата 3** — «за окно нет ни одной рабочей сборки» (отличается от 1 «журнала нет» и 2 «ошибочно снятые не 0»):
  так 13.11 нельзя случайно выдать демо-строку за недельный замер.
- Пояснение, почему «сверх сборки» по этим числам не считается: в тени к задачам сборки добавлены прежние задачи
  встречи — наборы разные, и разница «сборка минус способ 1» была бы неправдой.

## Проверка на живом журнале (09.11)

```
python scripts/zamer_v_ten_itog.py --с 2026-11-08 --по 2026-11-13

```

Это честная картина на сегодня: в журнале только демонстрационная сборка встречи 8 (помечена), рабочих строк нет.

1. Если рабочие сборки появятся — таблица покажет их числа, код 0.
2. Если нет — код 3 и прямое «наблюдения нет»; тогда решение принимается по срезу (`scripts/srez_ten_tekushchie.py`),
   и срез не выдаётся за недельный замер.

Платных вызовов нет, рабочая база не менялась.
