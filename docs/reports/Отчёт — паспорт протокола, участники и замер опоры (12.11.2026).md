# Паспорт протокола, участники и замер опоры — сделано (12.11.2026)

Три задачи из «Что осталось отдельной работой»: паспорт принятого протокола, участники (голоса + контекст + ручной
список), замер правила «проект только при прозвучавшем». Правило владелицы включено.

## 1. Паспорт принятого протокола

Что делает: запоминает числа и фразы принятого протокола — версию, число активных задач, число задач с ответственным,
формулировки задач, заголовки разделов — и после пересборки сравнивает. Расхождение не отменяет сборку, а даёт одну
карточку «Разбора»: «Паспорт протокола: после пересборки изменились факты».

- `core/pasport_protokola.py`: `снять`, `получить`, `сверить`, `карточка_при_расхождении`;
- таблица `protocol_passports` (один паспорт на встречу, новый заменяет прежний);
- `scripts/pasport_protokola.py --meeting N --create|--check|--all [--json]`;
- сборка вызывает сверку после сохранения протокола (карточка только при расхождении).

Живой паспорт встречи 11 снят: **v4, задач 6, с ответственным 6, знаков 3 668**; проверка — `ok`.
Тесты: `tests/test_pasport_protokola_1211.py` — 5 (снятие, новая/пропавшая задача, смена ответственного и заголовка,
нет паспорта, карточка при расхождении).

## 2. Участники: голоса + контекст + ручной список

- **Голоса** — как было: `voice_names` из распознавания, только с подписью реплики.
- **Контекст** — добавлены однозначные обращения из разговора: имя с заглавной и запятой/восклицанием, человек
  находится в «Команде» **однозначно**; имя в третьем лице («Анастасия сказала…») и отделы не берутся. Перебор
  ограничен словами «Команды» — на 47-минутной записи это 3–4 секунды, не минуты.
- **Ручной список** — поле `meetings.participants_manual`, API `PATCH /api/meetings/{id}/participants`
  (`{"names": "Иванов Иван, Петрова Анастасия"}`); сборка его не затирает, имена идут в раздел «Участники».
- Для встречи 11 в ручной список внесена Чекунова М.В. — она подтверждена владелицей, но по голосу не опознана.

Тесты: `tests/test_uchastniki_kontekst_1211.py` — 4 (обращение, третье лицо/отдел, ручной список, API).
