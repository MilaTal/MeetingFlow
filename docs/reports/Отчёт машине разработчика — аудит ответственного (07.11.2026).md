## Короткий ответ

Вопросы «это реальный сотрудник?» и «кто из них» появляются не потому, что имени нет в цитате, а потому, что код **не умеет сопоставить имя + отчество** с человеком «Команды»:

- `Team.find` знает только «фамилия + имя»; отчество не участвует (`core/people.py:97-108`, `246-256`, `392-404`).
- `Team.said` собирает слова из цитаты «мешком» и возвращает `Антон Антон`, `Сергеевич Сергеевич`, `Евгений Сергеевич Сергеевич Сергеевич` — полное ФИО после этого не находится (`core/people.py:139-165`).
- `Team.addressee` берёт слова **до первой запятой** и только когда модель не дала исполнителя: на встрече 7 — **0 попаданий из 44 цитат** (`core/people.py:172-185`, `core/gates.py:186-189`).
- `new_person_name` принимает «Имя Отчество» за нового человека — отсюда карточки «Это реальный сотрудник?» и фиктивные записи (`core/people.py:197-214`).
- Правило 22.10 в MeetFlow **не исполняется**: `ispolnitel_strazh.проверить` и `sushchestvennost.только_имя` нигде не вызываются.
- Голос в назначении почти не участвует: `из_подписи` требует точного ФИО и вызывается только при пустом исполнителе — **0 назначений из 26** пустых задач с цитатой.

## Предложения — без денег (P0)

1. `Team.find`: разбор третьего слова, ветка «имя + отчество → единственный человек» (`people.py:97-108`, `246-256`, `392-404`).
2. `Team.said`: возвращать непрерывный фрагмент без дублей и без подписей говорящих; порядок поиска — фамилия+имя, имя+отчество, одно имя (`people.py:139-165`).
3. `new_person_name`: «Имя Отчество» и два отчества фиктивными людьми не считать; однозначный человек — ставить, иначе задача без исполнителя без фиктивной записи (`people.py:197-214`).
4. `addressee`: искать имя в любом месте первой фразы, поддержать «Имя Отчество», проверять и когда модель дала имя (цитата сильнее) (`people.py:172-185`, `gates.py:185-210`).
5. Убрать `их` из `_FOREIGN` (`people.py:30`) — снимает 7 ложных карточек.
6. Голосовой ключ «фамилия + имя» вместо точного ФИО (`ispolnitel_golosom.py:123-138`, `voice_step.py:38-52`).
7. Решить явно, что с пустым исполнителем: включить `require_assignee` или оставить без карточки, но не молча (`themes/_default.json`, `gates.py:200-202`).
8. «Разбор»: читать `mention` (и `full_name` для `confirm_person`) — 26 карточек сейчас показывают пустое имя (`razbor.py:114`).
9. Данные: убрать фиктивные записи 238, 397, 398, 399 и переназначить 11 задач; 399 «Андрей Алексеевич» → Шаравин А.А.
