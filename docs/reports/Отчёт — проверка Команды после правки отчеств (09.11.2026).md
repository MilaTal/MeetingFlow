# Проверка «Команды» после правки отчеств (09.11.2026)

План, пункт 22. 9–10.11 владелица дописывает 46 отчеств вручную. Руками легко получить двойника («Иванов Пётр» и «Иванов
Пётр Сергеевич» рядом) или, наоборот, потерять тёзку. Сделан скрипт проверки — только на чтение, имена в консоль, в
репозиторий не попадают.

```
python scripts/proverka_komandy.py            # по живым проектам, с именами
python scripts/proverka_komandy.py --кратко   # только числа и итог
python scripts/proverka_komandy.py --проект 6
```

## Что проверяет

| Что | Как считается | Что значит |
|---|---|---|
| **Дубли** | одно полное ФИО дважды, без учёта регистра, «ё»/«е» и лишних пробелов | **ошибка**, код возврата **2** |
| **Тёзки** | одна фамилия и имя, разные отчества | норма (разные люди), но полезно видеть списком |
| **Без отчества** | запись из двух слов | что ещё не дописано |
| **Одно слово** | фамилия без имени | не человек «Команды», подсказка по такой записи не сработает |
