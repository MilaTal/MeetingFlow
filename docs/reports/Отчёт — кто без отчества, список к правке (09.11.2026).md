сделан скрипт: читает базу **только на чтение** и печатает, у кого в записи два слова (фамилия и имя).

```
python scripts/kto_bez_otchestva.py            # по живым проектам, с именами (в консоль)
python scripts/kto_bez_otchestva.py --кратко   # только числа
```

«Команде», код лишь подхватывает отчество в существующую запись (механизм готов, `team_sync`).
