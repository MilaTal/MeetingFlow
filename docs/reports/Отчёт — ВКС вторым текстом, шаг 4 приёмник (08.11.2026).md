## Что сделано

- **`время_из_имени(name)`** (`core/intake.py`) — время начала из имени файла в минутах: «работа с тендерами
  2026-11-06 11-59-7», «Выгрузка ВКС 06.11.2026 10.15», «15.10.2026 09:05». Дата из имени сначала убирается, иначе
  «06.11» читалось бы как время; пара «дд.мм» без года временем не считается. Времени нет — None.
- **Сверка по дате И времени** (`_по_времени`, `_meeting_for(..., имя)`): время нового файла сверяется со временем
  источников встречи; в пределах порога `MEETFLOW_INTAKE_TIME_GAP_MIN` (по умолчанию 180 минут) — та же встреча; явно
  другое время — своя встреча, чтобы две встречи одного дня не слились. Для «Общих встреч» поиск идёт так же:
  сначала встреча с тем же временем (и той же темой, если есть), иначе заводится новая.
- **Прикрепление выгрузки**: ВКС-выгрузка текстом рядом с записью ложится к той же встрече вторым источником
  (`local_asr=0`) — из него сборка берёт второй текст (шаги 1–3).
- **Поздняя выгрузка**: новый источник вида «расшифровка» запускает сборку по общему правилу автозапуска — как новая
  запись; отдельного выключателя нет.
