# Служебные строки истории не считаются цитатой (08.11.2026)

Перенос записки «Правки ERP и Планёрки 03–06.11» (06.11.2026), **п. 8**: «Строка секретаря не снимается: цитатой
считается только встречная неслужебная строка истории; служебные („нет в списке“, „ответственный →“, „сведено“) — не
цитата». В ERP из-за этого задача снималась по служебной записи.

## Что сделано

- **`rebuild.служебная_строка(цитата)`** — строка служебная, если начинается служебным оборотом: «ответственный»,
  «исполнитель перенесен», «срок», «сведено», «объединено из», «заменена прежней задачей», «возвращена по слову»,
  «работа снята человеком», «нет в списке», «подтверждена», «своя формулировка», «правка», «задача заведена», «не
  вошла в пересборку». Сверка без «ё» и регистра.
- **`drop_missing`**: цитата задачи держит её от снятия, только если она **не служебная** и есть в записи встречи. Если
  в поле цитаты оказалась служебная строка, работа в записи ею не доказана — задача снимается как «не вошедшая в
  пересборку», а не остаётся ложно.
- Правила, которые держат задачу, не тронуты: настоящая цитата записи — `kept_quote`; задача из протокола секретаря —
  `kept_secretary` (решение 05.11.2026); возвращённая владелицей — `kept_owner`; правленая человеком — карточка
  `rebuild_kept`.
