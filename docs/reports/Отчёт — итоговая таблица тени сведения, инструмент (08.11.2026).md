# Итоговая таблица тени сведения — инструмент готов (08.11.2026)

План, пункт 7, шаг 2: к 13.11 нужна одна таблица по журналу тени и решение владелицы. Чтобы 13.11 не собирать её руками,
сделан скрипт: журнал → таблица. Скрипт только читает журнал; базу не трогает, денег не тратит.

## Что умеет

```
python scripts/zamer_v_ten_itog.py --с 2026-11-08 --по 2026-11-13 --вывод итог.md
```

- читает `data/logs/svedenie_ten.jsonl` (или `--журнал`), битые строки считает и не роняет итог;
- окно дат `--с`/`--по` (по умолчанию с 08.11 по сегодня) — неделя наблюдения считается с 08.11;
- **демонстрационные строки отдельно**: строка с «демонстрация» в поле `чем` идёт в свой раздел и в недельный итог не
  попадает (владелице не выдаётся за рабочий замер);
- по каждой встрече: сборок, было, стало бы, объединено бы, сомнений, по предмету / контрагенту / подпроектам / через
  отдел, ошибочно снятых; строка «итого»;
- пары, которые объединил бы способ 1, — с основанием и частями (до 30 пар, остальные числом);
- **условие варианта C** — «ошибочно снятых 0, жёстко»: если хоть одна строка говорит иначе, скрипт пишет
  «условие варианта C нарушено» и возвращает код 2;
- пустой или отсутствующий журнал — понятное сообщение и код 1 (итог не выдумывается).

## Проверки

`tests/test_zamer_v_ten_itog_0811.py` — **5 passed**:

- рабочие и демонстрационные строки не смешиваются: демо-встреча 8 не попадает в рабочий итог;
- окно дат: 07.11 и 14.11 вне окна, 08.11 и 13.11 внутри;
- строка с `ошибочно_снятых: 1` → код 2 и предупреждение;
- пустого журнала достаточно, чтобы получить код 1 и сообщение;
- итог пишется в файл, условие варианта C и пары на месте.

## Прогон на живом журнале (08.11)

В журнале сейчас **одна строка** — та самая демонстрационная сборка встречи 8 на копии базы (0,0157 $). Поэтому:

- рабочие сборки — «строк нет»;
- демонстрационные — встреча 8: было 12, стало бы 11, объединено бы 1, сомнений 0, по предмету 1, ошибочно снятых 0;
- условие варианта C — да.

Это честная картина: за неделю тень считается на **рабочих** сборках, а их в журнале ещё не было. Демо-строку в
недельный итог не подставляем.
