# Проход без пунктов: очередь пуста, стенд проверен (09.11.2026)

В очереди плана нет ни одного пункта, который можно сделать без даты или без слова владелицы. По новому правилу плана
(«если очередь пуста — не выдумывать пунктов») проход ограничился проверкой стенда и записью в журнал.

```
Код: служба на текущем коде (старт 09.11 05:28:47)
База: quick_check ok, людей 405, встреч 6
Журнал тени: строк 1
Итог: стенд в порядке            КОД=0
```

```
python scripts/nastrojki.py
тень включена, сравнение включено (предел 150), способ 1 в бою выключен,
порог протокола 0.6, возврат абзацев включён, укрупнение включено
```

Настройки совпадают с решениями владелицы; мимо плана ничего не задано.

## Что ждёт (без изменений)

- **9–10.11** — отчества в «Команде», 46 записей; после — `kto_bez_otchestva --кратко` и `proverka_komandy --кратко`.
- **13.11** — замер одной командой и слово владелицы по способу 1.
- **По слову** — порог протокола (0.6 / 0.7 / 0.8 / только карточка), дата в поиске, широта меню встречи.
- **После решения** — пункт 23: включить способ 1 или выключить замер.

## Изменение в плане

Добавлено правило: **пустая очередь — не повод придумывать работу**. Проход в этом случае делает самопроверку, пишет
строку в журнал и останавливается; новые пункты появляются только из записок, отчётов с открытым хвостом или слова
владелицы. Это чтобы проходы не наращивали лишние скрипты и тесты «на всякий случай».

Платных вызовов нет, рабочая база не менялась.
