## Чем это не является

- Это **не** недельный замер: срез — один день, старые встречи, собранные до исправления тени (08.11). В журнал он не
  пишется, в таблицу 13.11 не подставляется.
- Это **не** решение о пороге сведения: 28 сомнений — наблюдение, а не ворота (вариант C).

## Как запускать

```
python scripts/srez_ten_tekushchie.py                      # все встречи с активными задачами
python scripts/srez_ten_tekushchie.py --встречи 7,8 --вывод срез.md
```

База открывается только на чтение (`PRAGMA query_only`), встречи не пересобираются, журнал не трогается. Есть и общий
инструмент недельной таблицы — `scripts/zamer_v_ten_itog.py` (журнал → таблица, демо отдельно).
