# Поиск по имени: проект и встреча — только имя (09.11.2026)

План, пункт 19. Слово владелицы 08.11.2026 про левую панель: «мы ещё хотели включить сюда поиск по имени только». Проверено
фактом: проект искался по имени, а встреча — по имени **или дате**, и правило жило в браузере, отдельно от списка.

## Что сделано

- **Правило поиска переехало на сервер:** `core/poisk_vstrech.py` — `подходит(встреча, запрос)` и
  `отобрать(встречи, запрос)`. Совпадение — по **названию** встречи, без регистра, «ё» = «е», лишние пробелы не в счёт,
  не больше 8 строк. **Дата в имя не входит** (прежде «06.11» показывал встречи).
- **Охват — как у списка:** поиск идёт через `ctx.scope_sql`, то есть по выбранному проекту; во «Все проекты» — по всем.
  Встречи другого проекта в выдачу не попадают.
- **Экран:** `app.js` — `показатьВстречиПоЗапросу` зовёт `GET /meetings/search?q=…` (кэш 30 с по запросу и проекту).
  Статика `?v=20261108mf73`.
- **Метки в выдаче** чистятся тем же `для_показа`, что и в реестре (без «из папки-приёмника:»).
