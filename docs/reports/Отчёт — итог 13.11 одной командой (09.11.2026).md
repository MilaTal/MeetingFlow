# Итог 13.11 — одной командой: неделя и срез в одном отчёте (09.11.2026)

План, пункт 7, шаг 2. Прежде 13.11 требовалось два запуска: таблица по журналу (`zamer_v_ten_itog.py`) и, если недели
наблюдения нет, отдельный срез (`srez_ten_tekushchie.py`). Теперь один запуск даёт оба раздела в одном отчёте.

## Что добавлено

`scripts/zamer_v_ten_itog.py --база <путь>`:

- сначала обычная таблица по журналу (рабочие сборки, демо отдельно, пары, спорные пары, готовность наблюдения);
- затем раздел **«Срез тени сведения по текущим задачам (без пересборки)»** — по базе, **только на чтение**;
- если срез не удался (нет базы и т.п.) — в отчёте строка «срез не сделан: причина», итог не падает;
- журнал не меняется: срез в него не пишет (проверено тестом).

Команда для 13.11:

```
python scripts/zamer_v_ten_itog.py --с 2026-11-08 --по 2026-11-13 --база data/meetflow.db --вывод "итог 13.11.md"
```

## Прогон на живых данных (09.11)


В отчёте: недельная таблица (рабочих строк нет), затем срез по четырём встречам — например, встреча 8: задач 10,
сейчас стало 9, способ 1 оставил бы 9, сомнений 0.
