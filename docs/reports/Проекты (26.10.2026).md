# Проекты (26.10.2026)

По замечаниям «вторые — структура проектов» и «третьи — папки-приёмники» (часть). Сделано: справочник проектов
и подпроектов с вариантами написания и архивом. Перенос остальной части проектов записан ниже отдельными пунктами.

## 1. Что сделано

- **Справочник проектов.** `projects` получил поля `aliases` (варианты написания), `active`, `archived`, `parent_id`
  (надпроект). Старые базы получают колонки миграцией, данные не переписываются.
- **API:** `GET /api/projects` отдаёт поля и разобранные варианты; `POST /api/projects` принимает название,
  варианты и надпроект; новый `PATCH /api/projects/{pid}` меняет название, варианты, надпроект и архив. Кольцо
  проектов и проект-надпроект сам себе запрещены (422).
- **Экран «Проекты»** в блоке администратора: дерево (надпроект → подпроекты), название, варианты написания через
  запятую, выбор надпроекта, «Сохранить», «В архив» / «Вернуть». Заведение нового проекта — там же.
  Архивные проекты не показываются в выборе проекта внизу панели; если текущий проект ушёл в архив, выбирается
  первый активный.
- **Варианты написания** — задел для подсказки распознаванию и поиску; в подсказку модели и в словарь распознавания
  пока не подключены (см. п. 2).

## 2. Что не перенесено и почему

| Пункт замечаний | Состояние |
|---|---|
| «Все проекты» в реестре задач, договорённостях, списке встреч | нет: экраны и API сейчас работают по выбранному проекту; нужен многопроектный слой отбора и проверка прав, отдельный шаг |
| Проект задачи и договорённости можно сменить вручную | нет: задача/договорённость наследуют проект встречи, поля смены нет |
| Поиск по всем проектам и сужение по названию | нет: поиск идёт по выбранному проекту |
| Подсказка модели и словарь распознавания по названиям/вариантам проектов | нет: варианты хранятся, но в prompt и ASR-словарь не подаются |
| Папка-приёмник в карточке проекта | частично: у каждого проекта уже есть своя папка в «Параметрах → Мониторинг» (выбранный проект); в справочнике проектов поля папки нет |
| Общая папка + папки проектов, обход верхнего уровня общей, запрет вложенных/совпадающих | нет: сейчас каждая папка — папка проекта; отдельного «общего» приёмника и проверки пересечений нет |
| Правило «е = ё» для всего | частично и раньше: ФИО/«Команда», поиск, тексты и метка папки уже сравниваются через «ё→е»; новые названия проектов хранятся как введены, сравнение — по нормализации |
