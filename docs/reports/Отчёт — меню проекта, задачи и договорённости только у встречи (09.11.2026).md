# Меню проекта: задачи и договорённости — только у конкретной встречи (09.11.2026)

Слово владелицы (со скриншотом левого меню): «реестр задач относится только к конкретной встрече — надо придумать, как
его выводить только для уже выбранной из реестра встречи; аналогично договорённости; статус проекта не релевантен для
отдельных встреч — убрать».

## Что изменено

- В меню выбранного проекта остались **две строки**: «Реестр встреч» и «Подготовка встречи».
- Убраны пункты **«Реестр задач»**, **«Договорённости по проекту»** и **«Статус проекта»** — они относились к проекту,
  а в MeetFlow задачи и договорённости принадлежат конкретной встрече.
- Задачи и договорённости открываются **со страницы встречи**, где они уже были:
  - вкладка **«Задачи»** (с числом) и кнопка **«Все задачи встречи в реестре»** — реестр открывается с фильтром
    «Встреча: дд.мм.гггг» (чип можно снять — тогда виден весь проект);
  - вкладка **«Договорённости»** — запрос `/agreements?meeting_id=<номер>`.
- «Статус проекта» убран из меню; маршрут `#status` остался для старых ссылок, но пункта в меню нет.
