# Тёзки при записи из двух слов: не угадывать (09.11.2026)

План, пункт 18 — последняя известная недоделка по ответственному из отчёта 07.11 (`29d4e86`).

## Что было не так

Общая «Команда» присылает человека как «Фамилия Имя» (без отчества). Если в проекте уже есть **двое** с такой фамилией
и именем и разными отчествами, прежний код заводил **третью** запись «Фамилия Имя» — то есть угадывал, кто это, и плодил
двойника. Правильное поведение: ничего не заводить, оставить как есть и показать карточку.

## Что теперь

`core/team_sync.py`, `sync_people`:

| В «Команде» пришло | В проекте сейчас | Что делает |
|---|---|---|
| Фамилия Имя (2 слова) | никого | заводит запись |
| Фамилия Имя | один человек (с отчеством) | не заводит — это он |
| Фамилия Имя | двое с разными отчествами | **не заводит**, кладёт в `неоднозначные` |
| Фамилия Имя Отчество | человек без отчества | дописывает отчество в существующую запись |
| Фамилия Имя Отчество | тот же человек | пропускает |
| Фамилия Имя Отчество | тёзка с другим отчеством | заводит второго (прежнее правило в силе) |

Карточка: сборка открывает «В «Команде» тёзки — кто именно, не понятно» со списком кандидатов и подсказкой уточнить
отчество в «Команде» проекта. При старте приложения (перенос людей без сборки) запись тоже не угадывается — в журнал
сервера пишется число «тёзок не угадано N».
