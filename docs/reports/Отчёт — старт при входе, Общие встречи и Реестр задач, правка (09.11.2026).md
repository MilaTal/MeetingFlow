# Старт при входе: «Общие встречи» → «Реестр задач» — причина и правка (09.11.2026)

Слово владелицы: «старт со страницы — Общие встречи — Реестр задач — опять не работает». Проверил на живой службе 8005:
при входе по «голому» адресу (портал или закладка) старт действительно мог открыться на «Все проекты» с пустым реестром,
а в браузере оставалась старая версия страницы. Нашлось **четыре** причины — все исправлены.

## Почему не работало

1. **Маршрутизатор успевал поставить `#dashboard` раньше загрузки проектов.** Проверка «адрес пуст?» в этот момент уже
   видела непустой хэш и пропускала выбор «Общих встреч»; проект оставался `0` («Все проекты»), а реестр задач для
   «Все проекты» пуст — 0 строк.
2. **Проект уходил в строку запроса.** `записатьПроектВАдрес` при пустом хэше собирал адрес как `?p=0` — параметр
   попадал в `location.search`, а `выбранныйПроект()` читает `p` только из хэша. В итоге в адресе `?p=0`, в памяти — 6,
   панель без выбранного проекта.
3. **Первая страница помнила проект только в `localStorage`.** Эффективный источник — `sessionStorage` вкладки: если
   человек до этого работал в другом проекте, старт открывался в нём, а не в «Общих встречах».
4. **`index.html` отдавался без `Cache-Control`.** Браузер держал старую страницу, и новые версии статики (`?v=mfNN`)
   не подхватывались до Ctrl+F5 — владелица видела прежний старт даже после правки.

## Что сделано

- `пришлиБезАдреса` запоминается **при загрузке скрипта** (до любых переходов); решение принимается в `загрузитьПроекты`
  **до** отрисовки панели и записи адреса — проект «Общие встречи» и `#dashboard?p=<id>` выставляются сразу и в
  `localStorage`, и в `sessionStorage`;
- адрес первой страницы пишется через `replaceState` (без лишней перерисовки); `записатьПроектВАдрес` при пустом хэше
  больше не может сделать `?p=` — подставляет `#dashboard`;
- старый мусор `?p=` из строки запроса убирается при входе; ссылки с адресом (`#meetings`, `#prep`, `#meetings/8`)
  по-прежнему не перебиваются;
- сервер отдаёт HTML с `Cache-Control: no-cache, must-revalidate` — новая версия страницы видна без Ctrl+F5; файлы с
  версией в адресе кэшируются как раньше;
- статика `?v=20261109mf79`.
