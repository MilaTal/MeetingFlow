# Правка протокола по замечаниям проверки — сделано в MeetFlow (17.11.2026)

Задание из передачи Планёрки/ERP `Для MeetFlow — как собирается и отрабатывается протокол, задание повторить
(17.11.2026).md`: проверка должна не только заводить карточки, но и **сразу править протокол** — патчами по
цитатам, до сохранения, без пересборки текста целиком.

## Что сделано

1. **Роль `verify`** — уже настроена: Qwen4 первая, DeepSeek вторая, OpenRouter через прокси `172.17.17.97:3128`
   (`data/models.json`). Не менялась.
2. **Модуль `core/pravka_po_zamechaniyam.py`** — чистые функции, базы и моделей не знает:
   - `отобрать` — только находки с цитатой и замечанием; стиль, «вероятно ложно», код и «было → стало» — мимо;
   - `промпт` — модель возвращает только `{"patches": [{"quote", "replacement", "why"}]}`;
   - `найти`/`применить` — поиск цитаты с учётом пробелов, регистра и ё=е; меняется только этот фрагмент;
   - `стало_хуже` — откат при пустом тексте, потере >20% знаков или >2 строк таблицы задач;
   - `отметить_исправленные` — применённые находки помечаются, карточек по ним нет. Цитата патча может быть шире
     цитаты находки: «Германович Андрей Игоревич.» внутри «## Участники\nГерманович Андрей Игоревич.» — находка
     считается исправленной, ложной карточки нет.
3. **Конвейер:** проверка и правка перенесены **до сохранения** протокола (`pipeline.py`):
   - `self.ver` (роль `verify`) → находки;
   - один вызов `self.gen` (роль `generate`, шаг `fix_findings`) → патчи;
   - применение/откат; `build_note` — «исправлено замечаний проверки — N»; карточка-справка со списком замен;
   - карточки `review_finding` — только по неприменённым находкам.
4. **Бюджет:** после дорогой проверки Qwen4 прогноз по всей цепочке (0,33 $) не пускал дешёвый DeepSeek. Для правки
   прогноз считается по **первой** точке роли (`worst_call_usd_primary`), запасные проверяются своим вызовом.
5. **Тесты:** `tests/test_pravka_po_zamechaniyam.py` — 11: 9 перенесённых + широкая цитата патча + сквозной
   конвейер (проверка → патч → сохранение, `build_note`, карточка, отсутствие ложной карточки). Связанные наборы —
   **67 passed, 2 пропуска** (набор v2 вехи 4 недоступен).
