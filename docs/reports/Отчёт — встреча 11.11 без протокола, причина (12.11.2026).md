# Встреча 11.11.2026 без протокола — причина и исправление (12.11.2026)

Вопрос владелицы: «вчера была загружена встреча от 11.11 — почему не сформирован протокол». Разобралась по фактам.

## Что в базе

Встреча №11 (11.11.2026, «Общие встречи»):
- источников — **0**, протокола нет, задач 0, статус «ждёт запись»;
- карточка №280 (11.11, 17:12): «Запись „запись2026-11-11 14-54-19.m4a“: длительность 0 мин вне окна темы»;
- карточка №282 (12.11, 09:03): «ни одна точка распознавания не сработала — Транс: таймаут; whisper-large: Cannot find an
  appropriate cached snapshot folder».

## Причина первая (главная): загружен обрывок записи

Файл в папке-приёмнике есть — `запись2026-11-11 14-54-19.m4a`, **278 630 байт**. Проверка ffprobe:

```
Duration: 00:00:16.58, bitrate: 134 kb/s
Audio: aac (LC), 44100 Hz, mono
creation_time: 2026-11-11T11:54:36Z   (13:54 по местному, телефон Android)
```

То есть запись длится **16,6 секунды**, а не встречу. Приёмник держит записи короче 3 минут («окно темы 3–90 мин»),
поэтому источник не создан, протокол не собирался. Сообщение карточки округляло 0,28 мин до «0 мин» — выглядело как
сбой, а не как «файл слишком короткий». Исправлено: теперь пишется «17 с».

## Причина вторая: распознавание было недоступно

Даже для полной записи распознавание в тот момент не сработало бы:
- **«Транс»** (`http://192.168.100.224:8021/transcribe`) не отвечает — таймаут `WinError 10060` (проверено сейчас:
  хост недоступен);
- **локальный whisper** искал кэш Hugging Face и падал «Cannot find an appropriate cached snapshot folder», хотя папка
  `whisper-large-v3` лежит в наборе моделей `VOICE_MODELS_DIR`.

Исправлено в коде:
1. `WhisperLocalASR._местная_модель`: имя модели (`large-v3`) превращается в папку `VOICE_MODELS_DIR/whisper-large-v3`;
   оба загрузчика (`_load`, `_load_point`) используют её, к Hugging Face не ходят.
2. В общем процессе службы MKL падал `mkl_malloc: failed to allocate memory` при загрузке large-v3 — потоки по числу
   ядер резервировали слишком много. Ограничены `OMP_NUM_THREADS=4`, `MKL_NUM_THREADS=4`: модель грузится за 16 с
   вместо падения.
3. Сообщение о короткой записи — в секундах.

## Проверка после исправления

- Локальная модель: загрузка из папки набора — **16 с**.
- Сквозное распознавание того же 16-секундного файла (копия, не приёмник): **65,5 с**, 192 знака текста — распознавание
  работает, «Транс» больше не обязателен.
- Служба 8005 перезапущена: PID 30932, старт 12.11 09:37:52, тема `mf_protocol`.

## Что нужно от владелицы

1. **Прислать полную запись встречи 11.11** в папку-приёмник (`P:\Technical\Протоколы встреч\Встречи по всем проектам`).
   Как только файл появится, приёмник создаст источник, локальный whisper распознает (медленнее «Транса», минуты), и
   протокол соберётся сам — автозапуск включён. Карточку №280/282 можно будет закрыть.
2. Если полной записи нет (телефон записал только 16 с) — встречу 11.11 придётся собрать по заметкам/расшифровке
   секретаря: приложите текст в «Материалы» встречи, протокол соберётся по нему.
3. «Транс» на 192.168.100.224:8021 стоит поднять на его машине — он быстрее локального распознавания; пока работает
   локальный запасной путь.
