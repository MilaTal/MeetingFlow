# Д2.2: смена проекта на встрече уводит в реестр нового проекта (08.11.2026)

Остаток решения владелицы 05.11.2026 по Д2 (перенос встречи): «смена проекта **уводит в реестр нового проекта**».
Серверная часть работала (встреча переезжает вместе с задачами), а экран после переноса оставался на списке встреч
прежнего охвата: задачи переехали, но чтобы их увидеть, проект приходилось переключать руками.

## Что сделано

- `web/static/nav.js`, окно «Переместить встречу»: после успешного переноса и обновления числа встреч у проектов
  вызывается выбор нового проекта — открывается **реестр задач нового проекта**, где уже видны переехавшие задачи.
  Прежний экран встречи в старом проекте больше не остаётся открытым.
- Версия `nav.js` поднята: `?v=20261108mf70`.
