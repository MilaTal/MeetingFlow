# Объект рядом с поручением — дописывается кодом (08.11.2026)

Пункт 8 плана, находка замера 05.11.2026: в выгрузке ВКС объект назван за минуту до разговора о работе («Прокал
Эльдаба, да… Колоночный профиль мы уже приняли, можно уже передавать»), модель задачу завела, а объект в формулировку
не вписала. Правило промпта не помогло даже в усиленной редакции (два прогона замера), поэтому объект дописывает код.

## Что сделано

- **`core/obekt_ryadom.py`**: объекты ищутся в куске выгрузки ВКС на ±2 минуты от цитаты:
  - по справочнику проектов и его вариантам — «Эль-Дабаа» и «Эльдаба» считаются одним названием (сверка по склейке
    без дефисов и по началу слов), «ё» = «е»;
  - по маркерам «объект», «проект», «прокал», «площадка» — так в выгрузке звучит «Прокал Эльдаба».
- Правило: **один объект и его нет в формулировке** — дописывается «— объект <название>»; объект уже назван — не
  трогаем; **два объекта и больше** — описание не меняется, оператору карточка «Объект рядом с поручением не ясен» с
  обоими вариантами и дословным куском.
- Подключено на всех путях заведения задачи: обычное поручение, «под вопросом», задача из единиц встречи
  (`pipeline._с_объектом`, время берётся из цитаты, а если цитата короткая без метки — из строки записи, где она
  прозвучала).
- Работает только когда у встречи есть второй текст (выгрузка ВКС); без выгрузки ничего не меняется.
