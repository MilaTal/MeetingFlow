В общей базе лежат только подтверждённые люди, поэтому «люди» и «подтверждены» в MeetFlow — одно число. Разница
«116 против 101» — неподтверждённые записи самой Планёрки: они в общую базу не идут по её же правилу. По
подтверждённым, внутренним и внешним числа совпадают.

Правило 24.10 «внешние контакты — только подтверждённые» выполняется свойством общей базы; MeetFlow показывает
внешних отдельным счётчиком и в списке с пометкой «внешний».

## 4. Что пришлось доделать

1. **Клон и запуск.** `pip install -e .` из `DEPLOYMENT.md` падал: setuptools видел в плоской раскладке несколько
   пакетов верхнего уровня (`public`, `skill`, `eval`, `themes`). Добавлен явный `[tool.setuptools.packages.find]`
   с `include = ["meetflow*"]`. venv не создавался: Python 3.14 на машине собран без модуля `venv`, все
   зависимости уже стоят глобально.
2. **Окончания строк.** При `core.autocrlf=true` падали побайтовые сверки общих модулей (md5): у части файлов
   эталонный хэш снят с CRLF, у `doubt_labels.py` — с LF, и одним режимом клона все проверки не проходили.
   Добавлен `.gitattributes` с точными окончаниями для четырёх файлов; сами тесты не менялись.
3. **Свои настройки.** `python -m meetflow` не читал `.env.local` (документация упоминала его только для ключа
   OpenRouter). Добавлено чтение `ИМЯ=значение` при запуске команды: файл вне git, переменная окружения главнее.
4. **Общая «Команда».** Новый коннектор `meetflow/connectors/team_shared.py`: путь `TEAM_SHARED_PATH`, иначе
   `team_shared.db` рядом с базой голосов; открытие `mode=ro`; счётчики «всего / подтверждены / внутренние /
   внешние / по отделам» и список людей. Экран «Общая команда» у супер-администратора, строка в «Мониторинге
   RealTime», `GET /api/monitoring/team-shared`, состояние в настройках проекта. Выключатель `TEAM_SHARED=off`
   соблюдается.
5. **База голосов.** Подключение уже было; путь задан через настройки MeetFlow и продублирован в `.env.local`.
   Администратор создан для подтверждения опасных смен; пароль только в `.env.local`, в git и отчёт не попал.
