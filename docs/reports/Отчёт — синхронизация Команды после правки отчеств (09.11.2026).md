План, пункт 31. Нашлось по факту: правка отчеств идёт в **общей** «Команде» (`team_shared.db` рядом с базой голосов, 81
человек, **46 без отчества**), а проверки читают **копию MeetFlow**. Копия обновится только когда откроют экран «Команда»
или пойдёт сборка — то есть после вашей правки 10–11.11 проверка могла показать старые 46.

## Что сделано

`scripts/sync_komandy.py`:

```
python scripts/sync_komandy.py           # сухой ход: что изменится
python scripts/sync_komandy.py --apply   # применить (сначала копия базы рядом)
```

- **сухой ход** показывает по каждому живому проекту: сколько отчеств допишется, сколько людей добавится, какие тёзки не
  угаданы (имена — в консоль, не в репозиторий); **ничего не пишет**;
- **`--apply`** делает копию базы `meetflow.db.до-sinhrona-<ддмм>`, затем `sync_all` — тот же механизм, что при открытии
  экрана; правила прежние (отчество дописывается в существующую запись, тёзки с разными отчествами не сливаются);
- пустая или недоступная общая «Команда» — код 3 и понятная строка.
