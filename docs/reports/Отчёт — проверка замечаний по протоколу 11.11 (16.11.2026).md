## Что дополнительно нашлось и исправлено

При проверке механизма (не только текста) найден **дефект ручного списка участников**: в базе
`meetings.participants_manual` встречи 11 лежало `???????? ?????? ??????????` — кириллица была записана не в UTF-8,
а API принял это молча. В тексте версии 4 Чекунова была вписана вручную, поэтому замечание 0 в документе было
закрыто, но механизм «дополнить участников» был сломан.

Исправлено:

1. Значение в базе заменено на **«Чекунова Марина Викторовна»** через штатную ручку
   `PATCH /api/meetings/11/participants` (тело в UTF-8, роль `project_admin`).
2. `web/app.py`, `set_participants`: имя без букв (например, `????`) больше не сохраняется — ответ **422**
   «Имя участника не распознано: в нём нет букв. Отправьте список в UTF-8». Пустая строка по-прежнему очищает список.
3. `core/pipeline.py`, `_с_ручными`: битые имена без букв не попадают в раздел «Участники» даже из старых данных.
4. Тесты: `tests/test_uchastniki_kontekst_1211.py` — добавлены проверки «битый список не идёт в участники» и
   «API не принимает имя без букв». Связанные наборы: **19 passed** (участники, исполнители-сокращения, паспорт).

## Почему версия 4 не перезапишется

Версия 4 помечена `protocol_hand_edited=1`; экран MeetFlow при таком протоколе **блокирует пересборку**
(`ПЕРЕСБОРКА_ЗАПРЕЩЕНА`). Это важно: автосборка версии 3 возвращала часть ошибок — «375 тысяч», отбор
завершённых заказов и блок «Из прежней версии». Принятая версия 4 — ручная, поэтому обычным нажатием «Пересобрать»
её не затрут. Если когда-нибудь понадобится принудительная пересборка, ручные решения придётся переносить заново —
это отдельная доработка, не дефект версии 4.
