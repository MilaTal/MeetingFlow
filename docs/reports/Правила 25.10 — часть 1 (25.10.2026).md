## Как сделано

1. `RunBudget.steps` считает вызовы по назначению шага; `max_calls_per_step = 12`; каждый вызов, включая переспрос
   ответа не в формате JSON, проходит проверку до обращения к модели. `CallJournal.run_id` пишется в каждую строку
   журнала; в итог прогона добавлены `run_id` и `step_calls`.
2. `RunReport.retryable` — истина только для недоступности модели и сети (`ConnectorError`, кроме обрыва ответа и
   предела). Очередь при таком сбое ставит строку снова: через 10 минут, затем через час, не больше двух повторов;
   каждый повтор — строка журнала с `run_id` и задержкой. Непроходящий сбой — одна карточка (вторая не плодится),
   с действием «Пересобрать».
3. Модуль `meetflow/core/speakers.py`: голос главнее аккаунта; аккаунт — только подсказка «… (аккаунт ВКС)»;
   с одного аккаунта два голоса и больше — аккаунт не ставится никому; нет данных — «Говорящий N»; аккаунт никогда
   не даёт исполнителя по «я сделаю». Есть подсказка для «Разбора голосов».
4. `choose_transcript`: текстом идёт своя локальная расшифровка; если она пустая или знаков меньше половины выгрузки —
   текстом выгрузка, причина в итоге сборки (`source_choice`, `source_reason`). Блоки двух расшифровок и сведение
   дублей не переносились — отменены.
