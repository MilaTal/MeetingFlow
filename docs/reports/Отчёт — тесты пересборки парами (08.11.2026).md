# Тесты пересборки парами (08.11.2026)

Перенос записки «Правки ERP и Планёрки 03–06.11» (06.11.2026), **п. 13**: «Тесты пересборки — парами: „цитата
осталась — задача остаётся“ и „цитаты нет — снимается“». В Планёрке этим правилом закрыты 18 падений: тесты, где
проверена одна сторона, позволяют поправить одну и молча сломать другую.

## Что сделано

`tests/test_peresborka_pary_0811.py` — каждая пара проверяется одним тестом сразу с двух сторон, на одной и той же
записи:

1. **Цитата есть / цитаты нет.**
   - задача с цитатой из записи — остаётся (`kept_quote`), статус «в работе»;
   - задача, чьей цитаты в записи нет, — снимается («не вошла в пересборку»), первая при этом не задета.
2. **Та же работа / другая работа под одной широкой цитатой** (широкая цитата несёт разные поручения, решение 04.11):
   - другая работа — НЕ замена, прежняя задача остаётся;
   - та же работа — замена, прежняя снимается, новая в работе.

Пара «служебная строка / настоящая цитата» (правка п. 8) уже закрыта тестами `test_sluzhebnye_stroki_0811`; пара
«цитата занята заменой / широкая цитата с разными работами» — тестами `test_citata_zanyata_0411`.
