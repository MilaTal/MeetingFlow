# Старт при входе: «Общие встречи» → «Реестр встреч» — причина и правка (09.11.2026)

Слово владелицы (вечернее уточнение): «не могу добиться, чтобы первая страница при переходе была Реестр встреч из
Общие встречи». До этого весь день старт вёл на «Реестр задач» — теперь по её слову первой страницей идёт **«Реестр
встреч»**. Причины, по которым старт вообще не срабатывал, остались те же — исправлены, ниже они и проверки.

## Почему не работало (найдено при разборе)

1. **Маршрутизатор успевал поставить адрес раньше загрузки проектов.** Проверка «адрес пуст?» в этот момент видела
   непустой хэш и пропускала выбор «Общих встреч»; проект оставался `0` («Все проекты»), экран — пустым.
2. **Проект уходил в строку запроса.** `записатьПроектВАдрес` при пустом хэше собирал адрес как `?p=0` — параметр
   попадал в `location.search`, а `выбранныйПроект()` читает `p` только из хэша. В адресе `?p=0`, в памяти — 6,
   панель без выбранного проекта.
3. **Первая страница помнила проект только в `localStorage`.** Эффективный источник — `sessionStorage` вкладки: если
   человек до этого работал в другом проекте, старт открывался в нём, а не в «Общих встречах».
4. **`index.html` отдавался без `Cache-Control`.** Браузер держал старую страницу, и новые версии статики (`?v=mfNN`)
   не подхватывались до Ctrl+F5 — владелица видела прежний старт даже после правки.

## Что сделано

- `пришлиБезАдреса` запоминается **при загрузке скрипта** (до любых переходов); решение принимается в `загрузитьПроекты`
  **до** отрисовки панели и записи адреса — проект «Общие встречи» и `#meetings?p=<id>` выставляются сразу и в
  `localStorage`, и в `sessionStorage`;
- клик по проекту и по «Общим встречам» открывает **«Реестр встреч»** (если он уже открыт — перерисовка, чтобы не
  остался прежний проект);
- адрес первой страницы пишется через `replaceState` (без лишней перерисовки); `записатьПроектВАдрес` при пустом хэше
  больше не может сделать `?p=` — подставляет `#meetings`;
- старый мусор `?p=` из строки запроса убирается при входе; ссылки с адресом (`#meetings/8`, `#prep`) по-прежнему не
  перебиваются;
- сервер отдаёт HTML с `Cache-Control: no-cache, must-revalidate` — новая версия страницы видна без Ctrl+F5; файлы с
  версией в адресе кэшируются как раньше;
- статика `?v=20261109mf80`.

  **«Реестр встреч»**, видны встречи 06.11 и 03.11.
- Клик по «Общим встречам» из «Реестра задач»: `#meetings`, заголовок «Реестр встреч», встречи на месте.
- Страница `app.js?v=20261109mf80`; `/` отдаётся с `Cache-Control: no-cache, must-revalidate`.
- Служба 8005 работает (PID 60356), после правки перезапуск не требовался — изменились только файлы фронта.
- Тесты: `tests/test_vybor_proekta_otkryvaet_vstrechi_0811.py` и три файла со сторожами версий — **15 passed**;
