# Для локальной машины MeetFlow — Д3 заменён: проект только в строке над экраном (05.11.26)

Решение владелицы 05.11.2026 по макетам: вариант «проект только над экраном». Раздел Д3 записки `07b1234` отменяется и заменяется этим, Д4 уточняется. Вопросов владелице не задавай, денег не нужно. Порядок прежний: сначала Д1 и Д2 (`cd0448a`, `3d3da09`), затем Д3 и Д4 вместе одним разделом.

## Левая панель

1. Выбора проекта в левой панели **нет совсем**: ни кнопки «Проект: …», ни списка, ни блока «Проекты». Вверху панели — название системы вместо «Проект — …».
2. Состав пунктов меню, их названия, «Инфо по проекту» (Д5) и служебные пункты под чертой не меняются. Строка поиска из пакета Г над меню остаётся, если уже сделана.
3. Сдвиг шапки панели от длины названия проекта (А2-П7) исчезает сам: проекта в шапке нет.

## Строка над экраном — единственное место выбора

1. На всех экранах, зависящих от проекта, первой строкой рабочей области: название проекта с шевроном, подчёркнутое пунктиром, затем «·» и раздел приглушённым цветом. Вид «текстом», как в `615b052`. Экраны — по Д4 записки `07b1234`.
2. Нажатие на название открывает всплывающий список под строкой, поверх страницы; меню и данные не сдвигаются. Escape и выбор закрывают его, фокус возвращается на название.
3. Состав списка, сверху вниз: поле «Найти проект…»; «Все проекты»; «Общие встречи»; черта; подпись **«Все проекты»** (без слов «по алфавиту»); все проекты по алфавиту, справа число открытых задач; черта; «+ Новый проект». **Блока «Недавние» нет.** Текущий проект подсвечен, разметка — кнопки с `aria-current`.
4. На странице встречи название проекта без шеврона и без списка: «Проект · Встреча дд.мм.гггг · название». Сменить проект — из «Реестра встреч», смена уводит в реестр нового проекта (Д2).
5. На общих экранах («Команда», «Параметры», «Модели», голоса, «Оформление») строки нет. Заголовок вкладки браузера «Проект · раздел».
6. Новая вкладка открывается с последним выбранным проектом (`720ecca`), первый вход — «Все проекты» (`0c6f7bd`). Список недавних для этого не нужен: хранится только последний выбор.
7. На ширине 400 px строка остаётся первой строкой экрана, список во всю ширину.

## Как проверить

1. В левой панели 0 элементов выбора проекта на всех экранах и ролях.
2. Строка проекта есть на 7 экранах из 7, на встрече без шеврона, на общих экранах её нет.
3. В списке нет «Недавние» и «по алфавиту»; поиск находит проект по части названия, е = ё.
4. Клавиатура: Tab доходит до названия проекта в строке одним шагом, Enter открывает список, Escape закрывает, фокус на названии.
5. Критерии Д1 и Д2 после правки не ухудшились, весь набор тестов. Тест, закреплявший выбор в левой панели, переворачивай, не удаляй.
6. Снимки на 1500 и 400 px: список закрыт и открыт, встреча, общий экран.
