## 1. Дефект: пустая папка с файлом-меткой не принимается

Владелица выбрала папку `P:\Technical\Протоколы встреч\Встречи по всем проектам\Адресный учет на складе`, в ней один файл «ЭТО ПАПКА-ПРИЕМНИК ЗАПИСЕЙ.txt» (0 КБ). MeetFlow ответил: «папка не пустая и без файла-метки «ЭТО ПАПКА-ПРИЁМНИК.txt»».

Причина: `meetflow/connectors/watch_folder.py` знает одно имя метки `MARKER = "ЭТО ПАПКА-ПРИЁМНИК.txt"` и сравнивает буквально. Метка владелицы — с «Е» вместо «Ё» и со словом «ЗАПИСЕЙ». Планёрка эту беду уже решала 07.10.26: `planerka/webapp/app/services/watch_folder.py` — `MARKER_NAMES` (оба имени — Планёрки и ERP) и сравнение без различия «ё/е» и регистра (см. её docstring «найдено 07.10.26 на живом экране владельца»). Перенести 1 в 1 (код Планёрки только читать): принимаются «ЭТО ПАПКА-ПРИЁМНИК.txt» и «ЭТО ПАПКА-ПРИЁМНИК ЗАПИСЕЙ.txt» в любом написании «ё/е» и регистре. Тест до правки: папка с «ЭТО ПАПКА-ПРИЕМНИК ЗАПИСЕЙ.txt» принимается.

## 2. Структура папок-приёмников: общая + своя у проекта

Владелица: «если создан отдельный проект — у него должна быть возможность выбрать свою папку-приёмник; для всего остального — общая папка». Пример на машине:
- общая — `P:\Technical\Протоколы встреч\Встречи по всем проектам`;
- проекта «Адресный учёт на складе» — её подпапка `…\Встречи по всем проектам\Адресный учет на складе`.

Сделать:
1. **Общая папка-приёмник** — как сейчас (Параметры системы), запись из неё → встреча без проекта (проект можно определить по тексту/названию файла подсказкой, как в Планёрке, или выбрать вручную).
2. **Своя папка у проекта** — в карточке проекта (справочник проектов из пункта 1а): поле «Папка-приёмник проекта», тот же порядок смены (адрес и повтор → система показывает, что заберёт первый проход → пароль суперадминистратора), те же запреты (корень диска, домашняя, «Документы», «Рабочий стол», «Загрузки», папка приложения; непустая — только с файлом-меткой). Запись из папки проекта → встреча сразу с этим проектом.
3. **Своя папка может лежать внутри общей** (как в примере). Обход общей папки **не берёт** файлы из подпапок, назначенных проектам (и вообще берёт только файлы верхнего уровня общей папки — проверь, как сейчас, и запиши), чтобы одна запись не стала двумя встречами. Две папки не могут совпадать; папка одного проекта не может быть папкой другого.
4. Обход: один общий цикл по всем папкам (общая + папки проектов) с тем же интервалом (сейчас 900 с), в мониторинге — по строке на папку (путь без учётных данных, последний обход, принято файлов, ошибка).
5. Экран: в «Параметрах системы» — общая папка; в «Проектах» у каждого проекта — его папка (пусто — записи проекта кладут в общую). Подсказка под полем — коротко.

Тесты до правки, полный прогон, коммит, push. Проверка на машине: владелица задаст обе папки — общая и «Адресный учет на складе»; положить тестовую запись в папку проекта — встреча получила проект; в общую — без проекта; одна запись — одна встреча. Отчёт «Папки-приёмники (26.10.2026)», копия в `P:\Technical\AI Projects\MeetFlow\Отчёты\`.

## 3. Правило «е = ё» для всего (дополнение владелицы 26.10.2026)

Основное имя метки — с «е»: «ЭТО ПАПКА-ПРИЕМНИК.txt» (и «ЭТО ПАПКА-ПРИЕМНИК ЗАПИСЕЙ.txt»), «ё» тоже принимается. И шире — **во всех системах, для всех записей и названий оба написания равны**: ФИО и «Команда», проекты и их варианты, контрагенты, поиск, сверка формулировок задач, темы, имена файлов, сроки словами. Хранимые данные не переписывать — сравнивать через общую нормализацию («ё»→«е»). В монорепозитории это делается пакетом «е и ё одинаково везде (26.10.2026)» — перенести по смыслу. Тест: «Королёв» = «Королев», «Озёрное» = «Озерное», поиск «приёмка» находит «приемка».
