# Изменения

## 1.0.0

Первая публичная версия.

- Веб-приложение MeetFlow: приём записи встречи, разбор поручений с проверкой кодом, сверка с «Командой»,
  карточки оператору, протокол и реестр, выгрузка в Word, роли пользователей.
- Тематики в JSON и коннекторы-подключаемые модули; пульт «Модели» — маршруты по ролям с резервом и откатом.
- Движок без веба с тремя наборами eval.
- Защита: реплики, обращённые к самой системе, помечаются и уходят оператору; досмотр моделью роли `guard`;
  фильтр выхода протокола.
- Плагин Claude Code: скилл `meetflow`, проверки срабатывания.
