# Наборы проверки (eval)

| Файл | Что |
|---|---|
| `cases.json` | основной набор, 15 кейсов |
| `cases_live.json` | живая речь, 12 |
| `cases_blind.json` | слепой, 10 — прогонять один раз после правок и ничего под него не править |
| `run_eval_meetflow.py` | прогон через конвейер, судья — код по реестру и карточкам |
| `test_instrument_and_attacks.py` | тест прибора (пустая модель обязана провалиться) и атаки на расход |

```bash
python run_eval_meetflow.py --set cases --llm mock --label <метка>
```

На заглушке наборы меряют заглушку, а не систему: её регулярное выражение знает только «Фамилия Имя, …».
Настоящая полнота — на модели. Точность (ложные записи) осмысленна и на заглушке: на ней основной набор даёт 8 из
15, живая речь — 4 из 12, слепой — 5 из 10. Часть ожиданий основного набора записана до правила «спорная задача заводится сразу, без исполнителя» и ждёт, что задачи не будет.

Набор, по провалам которого правили код, засвечен: его результат больше ничего не доказывает, для следующего замера
нужен новый отложенный набор. Сначала проверяется прибор — на заведомом ответе, — потом система.
