## 3. Неиспользованные решения, применённые здесь

1. **Тёмная тема.** В Планёрке предлагалась («переключатель тёмной темы»), но не была построена. Сделана: авто по `prefers-color-scheme` плюс явный выбор на экране «Оформление». Акцентный текст в тёмной теме осветляется через `color-mix(var(--accent) 55%, #fff)`.
2. **Палитра ролей из BPMN-схем.** В схемах процесса Планёрки (`bpmn_planerka_3009.py`) были цвета исполнителей, которых не было в интерфейсе: оператор `#1d4ed8`, модель `#6d28d9`, локальное распознавание `#15803d`, хранилище `#b45309`, супер-админ `#c2410c`. Во framework это метки `.actor-*` в журнале вызовов и истории статусов: видно, кто сделал изменение — человек, модель или система.
3. **Акцентные тени `.card-output`** (`0 6px 20px` цветом акцента) приняты в ERP; здесь привязаны к палитре через `--accent-shadow`.
4. **Отклонённые палитры** Планёрки — пресеты (раздел 2).

## 3а. Палитры для новых проектов (исследование 03.10.26)

Зелёные и индиго заняты проектами-примерами (Планёрка, ERP) и пресетами, поэтому для новых проектов подобраны восемь приглушённых палитр вне этих тонов. Ориентиры — ведущие продукты работы с документами и встречами через ИИ: Supabase, Mintlify, Vercel/Geist, Linear, Harvey, Anthropic, Granola, GitBook. Их фирменные цвета в большинстве не проходят норму контраста для белого текста (Supabase 2,0, Claude 3,1, GitBook 3,3, Mintlify 3,9). Поэтому взят характер цвета, а не сам цвет: тон сохранён, светлота опущена до корпоративного уровня. Полный отчёт с источниками — `_intermediate/digests/digest_PALETTE_RESEARCH.md`.

|---|---|---|---|---|---|
| `petrol` | `#1d5e69` | `#4fa3b1` | 7,35 | Mintlify / Supabase, сдвиг в сине-зелёный | медицина, фарма, экология |
| `ocean` | `#245a8c` | `#6a9fd4` | 7,20 | Vercel / Otter | ИТ, логистика, госзаказчики |

| `graphite` | `#3f4249` | `#9a9ea8` | 10,06 | Harvey: акцент — это чёрный | юридические документы, договоры |
| `ochre` | `#8a5a12` | `#d29a45` | 5,91 | Granola, тёплые нейтрали | образование, HR |
| `clay` | `#a14e36` | `#d08a74` | 5,74 | Anthropic / Claude | стройка, девелопмент |

Правила выбора. Clay и copper близки по тону (13° и 21°): в одном портфеле проектов берётся одна из двух. Graphite на кнопке близок к цвету текста, поэтому ссылки в нём подчёркиваются. Палитры генерирует `scripts/gen_palettes.py`: CSS руками не правится. Тест `tests/test_design_palettes.py` считает контраст прямо из CSS и не пропустит палитру ниже 4,5. Этот тест при первом запуске нашёл, что прежняя палитра по умолчанию emerald ссылкой на фоне страницы даёт 4,46. Текст в ней сделан темнее (`#1b7a52`), кнопки остались исходного цвета `#1f845a`.

Что взято из Supabase без смены общего подхода:

- моноширинный шрифт для служебных меток — номеров, дат, меток исполнителей;
- общее фокус-кольцо цветом акцента для всех элементов управления;
- в тёмной теме подложки и выделения считаются от акцента текущей палитры (раньше были жёстко зелёными), а акцентный текст светлеет, как у Supabase и Mintlify.

Тёмная тема по умолчанию и насыщенный зелёный Supabase не взяты: аудитория корпоративная, яркие цвета владелец отклонял.

## 4. Компоненты и правила экрана

- Две роли карточек: `.card` — зона ввода (градиент `--card-top → --card-bottom`), `.card-output` — выдача (белая, акцентная тень).
- Главные кнопки — `.btn-primary`, заливка акцентом и тень; второстепенные — мягкая заливка `--accent-soft`. Акцент усиливают тенью, а не размером и не новым цветом (решение Планёрки 29.09).
- Таблицы: только горизонтальные разделители, шапка 12,5/600 без переноса, выравнивание по верху, номер с 1 и дата постановки мелко под номером.
- Строка «Откуда» над документом: мягкая заливка, акцентная черта слева.
- Панель замечаний справа шириной 340 px, текст документа до 110 знаков в строке.
- Зона перетаскивания файлов: пунктирная рамка, подсветка при заносе.
- Правила замера (скилл `screen-check`): не больше пяти размеров шрифта, нет горизонтальной прокрутки, строка 45–90 знаков, главное действие в первом экране, высота страницы ≤ 1,5 окна, проверка двух ширин (1280 и 1500+).

## 5. Документы Word

Times New Roman 12 pt (корпоративный стиль владельца), заголовки — настоящими стилями, markdown-таблицы — таблицами Word, без `**` и обратных кавычек. Значения задаются в теме: `design.document_font`, `design.document_size_pt`.
