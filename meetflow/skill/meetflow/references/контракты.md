# Контракты скилла meetflow — движок engine

Справочник для того, кто подключает другую модель, другой реестр или пишет свой конвейер по этому скиллу.
Контракты MeetFlow — в его репозитории: `docs/PLUGIN_GUIDE.md`, `meetflow/connectors/base.py`, маршруты моделей —
`meetflow/connectors/llm_routes.py`.
Код — `engine/meeting_registry`, промпты — `prompts.py`.

## Ответы модели

Извлечение поручений, один вызов на кусок записи:

```json
{"assignments": [{"line": 5, "to": "Назаров", "action": "подготовить спецификацию на фильтры", "due": "до пятницы"}]}
```

Номер строки — из квадратных скобок входа. Цитаты в ответе нет: её берёт код. Тип не тот (null, строка,
словарь вместо списка) — кусок не разобран, карточка `chunk_failed`.

Закрытия, один вызов на встречу, только если код нашёл кандидатов:

```json
{"closures": [{"task_id": 12, "phrase": 3}]}
```

Пара (задача, фраза) засчитывается, только если код сам предложил эту фразу этой задаче.

Разрешающий агент, один вызов на шаг:

```json
{"tool": "find_person", "args": {"name": "Марина"}}
```

Инструменты: `find_person`, `participants`, `read_lines`, `search_registry` — наблюдение; `assign`,
`mark_duplicate`, `accept_new`, `to_operator` — решение. Аргументы не словарём — пустые. Неизвестный
инструмент — наблюдение с ошибкой, записи нет.

## Исходы прогона

`done` — встреча обработана. `degraded` — обработана правилами, локальная модель была недоступна.
`partial_limit` — встреча сохранена, часть спорных пунктов осталась у человека по потолку. `stopped_by_limit`
— остановка до записи, встреча не сохранена. `rejected` — источник не принят, встреча не создана.
`duplicate` — то же содержимое уже обработано. `failed` — ошибка настройки или внутренняя ошибка,
карточка человеку.

## Виды карточек оператору

`assignee` — задача заведена без исполнителя: тёзки, искажённая фамилия без имени, человек не из «Команды»,
отдел без руководителя (кандидаты внутри, говорившие на встрече — первыми; решение владельца 03.10.26).
`held_task` — поручение не внесено, нужна проверка: нет опоры в записи, не поручение, отчёт о сделанном
(причина в заголовке, цитата внутри).
`suspicious_text` — реплики, обращённые к системе. `mass_closure` — слишком много закрытий разом.
`chunk_failed`, `closing_failed` — часть разбора не выполнена. `limit` — сработал потолок. `degraded` —
протокол без модели. `no_date` — файл без однозначной даты. `setup`, `provider`, `internal_error` —
технические.

## Реестр (SQLite)

`meetings` — встреча, отпечаток источника (уникален), статус, текст протокола. `tasks` — задача,
ответственный (id из «Команды» или текст как прозвучало), статус `active / done / dropped`, срок, дата
постановки и закрытия, встреча-источник, номер строки, цитата, ключ идемпотентности. `task_history` —
каждая смена статуса с цитатой и встречей-основанием. `cards` — очередь оператору. `runs` и `run_steps` —
журнал прогонов: шаги, токены, секунды, стоимость, ошибки.

## «Команда»

```json
{"people": [{"id": "u05", "full_name": "Назаров Константин", "department": "ОЛГ", "aliases": []}],
 "departments": {"осн": {"name": "Отдел закупок", "head_id": "u06"}}}
```

Порядок в `full_name` — «Фамилия Имя». Отдел без руководителя — `head_id: null`, поручение такому отделу
уходит карточкой.

## Переменные окружения

`MR_MODEL` — модель в Ollama. `MR_OLLAMA_URL` — адрес, по умолчанию 127.0.0.1:11434. `MR_ALLOWED_HOSTS` —
белый список нелокальных адресов внутри контура. `MR_NUM_CTX`, `MR_TIMEOUT`. Потолки — `MR_MAX_CALLS`,
`MR_MAX_STEPS`, `MR_MAX_CHARS`, `MR_CHUNK_CHARS`, `MR_MAX_CHUNKS`, `MR_MAX_COST_USD`, `MR_MAX_SECONDS`,
`MR_MAX_ARTIFACTS`. Цены для пересчёта «как по API» — `MR_PRICE_IN`, `MR_PRICE_OUT` за миллион токенов.
